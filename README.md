# Broadser for Mac — downloads

The disk images and update files of **Broadser for Mac** from
[broadser.kens-toolbox.com](https://broadser.kens-toolbox.com), one GitHub release per
version. The source lives elsewhere; this repository only holds what people download.

- **Download:** https://broadser.kens-toolbox.com/mac/download/latest (the newest
  `Broadser.dmg`, signed with Apple's Developer ID and notarized).
- **Updates:** installed copies read the feed on broadser.kens-toolbox.com and download
  the `.zip` of the release it names. Each update must be signed by the same developer,
  and only a newer version is installed.
- **The Mac App Store version** is updated by the App Store, not from here.

Questions: https://broadser.kens-toolbox.com/support
